Thumbpad

Jadikan ponsel Android Anda trackpad, keyboard, serta remote media dan volume untuk PC Windows, cukup lewat Wi-Fi rumah.

Unduh untuk Windows

Windows 10 atau 11 · gratis · terpasang dalam hitungan detik

Tonton cara menyiapkannya

Cara menyiapkan

  1. Jalankan ThumbpadSetup.exe. File ini belum memiliki tanda tangan digital, jadi Windows mungkin menampilkan kotak biru ini: klik Info selengkapnya, lalu Tetap jalankan.
    1
    2
  2. Klik Next, lalu Install. (Untuk saat ini, penginstalnya hanya tersedia dalam bahasa Inggris.) Jika Windows meminta izin untuk membuat perubahan, klik “Ya” agar Thumbpad ikut berjalan saat Windows dinyalakan. Setelah selesai, jendela untuk memasangkan ponsel akan terbuka dengan kode QR.
    1
    2
  3. Saat Windows menanyakan akses jaringan, klik Izinkan. Ponsel Anda terhubung ke PC melalui Wi-Fi lokal.
  4. Pasang aplikasi Thumbpad dari Google Play di ponsel Android Anda. Pastikan ponsel dan PC terhubung ke jaringan Wi-Fi yang sama.
  5. Di aplikasi, ketuk Pasangkan PC lalu pindai kode QR di PC Anda. Anda hanya perlu melakukannya sekali.

Dapatkan aplikasi ponselnya

Thumbpad untuk Android Gratis di Google Play. Pasangkan dengan aplikasi Windows di atas.
Sudah terpasang? Klik kanan ikon Thumbpad di baki sistem (dekat jam) untuk memasangkan ulang atau keluar. · Semua unduhan
