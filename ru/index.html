Thumbpad

Используйте Android-телефон как тачпад, клавиатуру и пульт для медиа и громкости на ПК с Windows через домашний Wi-Fi.

Скачать для Windows

Windows 10 или 11 · бесплатно · устанавливается за секунды

Видео о настройке

Настройка

  1. Запустите ThumbpadSetup.exe. У программы пока нет цифровой подписи, поэтому Windows может показать это синее окно: нажмите Подробнее, а затем Выполнить в любом случае.
    1
    2
  2. Нажмите Next, затем Install. (Пока установщик есть только на английском.) Если Windows спросит, разрешить ли внесение изменений, нажмите «Да», чтобы Thumbpad запускался вместе с Windows. В конце откроется окно сопряжения с QR-кодом.
    1
    2
  3. Когда Windows запросит доступ к сети, нажмите Разрешить. Телефон подключается к ПК через вашу локальную сеть Wi-Fi.
  4. Установите приложение Thumbpad из Google Play на Android-телефон. Телефон и ПК должны быть подключены к одной сети Wi-Fi.
  5. На ПК откройте скрытые значки (^) рядом с часами, щёлкните правой кнопкой мыши по значку Thumbpad и выберите Сопрячь устройство…. Затем в приложении нажмите Сопрячь ПК и отсканируйте QR-код. Это нужно сделать всего один раз.
    1
    2
    3
    4

Приложение для телефона

Thumbpad для Android Бесплатно в Google Play. Выполните сопряжение с программой для Windows выше.
Уже установили? Щёлкните правой кнопкой мыши по значку Thumbpad в области уведомлений (рядом с часами), чтобы заново выполнить сопряжение или выйти. · Все загрузки
